# GlassGuard 1.0 공개 베타
스마트 글라스·초소형 카메라·전자기기 탐지 보조 PWA. 서버 없이 실행됩니다.

배포: Settings → Pages → Deploy from a branch → main / (root) → Save.

광학: 카메라 시작 후 물체를 고정하고 자동 반사 비교 또는 수동 기준 영상 비교를 사용합니다. 밝은 점은 카메라를 확정하지 않습니다. 눈에 조명을 비추지 마세요.

블루투스: 사용자가 선택한 BLE 기기의 이름 및 지원되는 경우 광고 신호를 확인합니다. 전체 검색은 불가합니다.

자기장: 지원 기종에서 실제 자기장 변화를 측정합니다. RF 측정이나 기기 식별 기능은 아닙니다.

실제 스마트폰 및 실물 탐지 성능 미검증. 영상 저장·외부 전송 없음. 허가된 장소와 물체만 점검하고 결과만으로 사람을 지목하지 마세요.
